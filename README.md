# مصحف لمسی — SVG عثمانی + QCF4

نمونهٔ اولیهٔ یک وب‌اپ برای نمایش **مصحف مدینهٔ ۱۵‌سطری** با ظاهرِ برداریِ مصحف و تعامل در سطح کلمه است.

## ایدهٔ اصلی

این پروژه دو منبع را عمداً از هم جدا نگه می‌دارد:

| لایه | منبع | مسئولیت |
|---|---|---|
| نمایش | [MushafDatabase Ligature-Based SVG](https://github.com/mushafdatabase/MushafDatabase-Ligature-Based-SVG) | ظاهر چاپی، شکست دقیق خطوط، علائم، و hit-area گرافیکی کلمات |
| داده | [quran-qcf4](https://github.com/MohamadHajjRabee/quran-qcf4) | متن کلمه، `verse_key`، موقعیت کلمه و توسعه‌های آینده مانند صوت/ترجمه |

> فونت‌های QCF4 روی SVG رسم نمی‌شوند. SVG لایهٔ بصری مرجع است و QCF4 فقط آن را enrich می‌کند؛ بنابراین ظاهر مصحف با فونت دیگری بازچینی نمی‌شود.

## امکانات نمونهٔ اولیه

- لود هر یک از ۶۰۴ صفحه از SVG رسمی‌نما، به‌صورت responsive
- لمس/کلیک روی هر گروه کلمهٔ SVG (`md-word-*`)
- بزرگ‌تر کردن محدودهٔ لمس برای موبایل با hitbox شفاف
- نمایش متن عثمانی، املایی، سوره، آیه، خط و شناسهٔ SVG کلمه
- همگام‌سازی اولیه با `pages/NNN.json` از QCF4
- پیمایش صفحه و ورود مستقیم شمارهٔ صفحه
- هایلایت کلمهٔ انتخابی و آیهٔ شامل آن
- **لایهٔ وقف و ابتدا:** رنگ‌آمیزی **قرمز** برای کلمهٔ وقف و **آبی** برای کلمهٔ ابتدا، از روی جدول کلمات
- لینک مستقیم به SVG و JSON استفاده‌شده برای هر صفحه

## نشانه‌های وقف و ابتدا

یک جدول کلمه به برنامه داده می‌شود و روی مصحف رنگ می‌گیرد:

| رنگ | معنا |
|---|---|
| 🔴 قرمز | **وقف** — کلمه‌ای که رویش می‌ایستیم (به‌همراه علامت وقفِ بعد از آن) |
| 🔵 آبی | **ابتدا** — کلمه‌ای که قرائت از آن آغاز می‌شود |

```bash
python3 scripts/build_annotations.py data/annotations/جدول-شما.tsv
```

هر ردیف در برابر خود مصحف اعتبارسنجی و به نشانی دقیق `سوره:آیه:شمارهٔ کلمه` تبدیل می‌شود؛
ردیف نگاشت‌نشده بی‌صدا دور ریخته نمی‌شود و گزارش می‌گیرد. قالب کامل جدول، حالت دو فایل
جدا، رفع ابهام کلمه‌های تکراری و لایهٔ پایهٔ مشتق از علامت‌های چاپ‌شدهٔ مصحف در
[`ANNOTATIONS_FA.md`](./ANNOTATIONS_FA.md) توضیح داده شده است.

## اجرا

این پروژه وابستگی ندارد. از داخل همین پوشه یک وب‌سرور محلی اجرا کنید:

```bash
cd mushaf-touch
python3 -m http.server 4173 --bind 0.0.0.0
```

سپس مرورگر را باز کنید:

```text
http://localhost:4173
```

در حالت پیش‌فرض (`asset-mode.js` روی `auto`)، برنامه ابتدا assetهای local را بررسی می‌کند؛ اگر هنوز استخراج نشده باشند، فقط در محیط توسعه از GitHub Raw استفاده می‌کند. پس از اجرای حالت local، درخواست‌ها از همان سرور محلی خوانده می‌شوند.

## بستهٔ local برای سرور شخصی

پوشهٔ `vendor/` شامل نسخهٔ فشردهٔ assetهای لازم است که از clone کم‌عمق و sparse دو ریپوی منبع ساخته شده‌اند:

```text
vendor/
├── mushafdatabase-svg-v1.01.tar.gz  # 604 صفحهٔ SVG، حدود 75 مگابایت فشرده
├── quran-qcf4-data.tar.gz           # 604 JSON و indexهای مورد نیاز
├── SHA256SUMS
└── SOURCES.md
```

برای توسعهٔ کاملاً local روی کامپیوتر خودت اجرا کن:

```bash
./scripts/start-local.sh
```

این دستور در صورت نیاز assetها را استخراج می‌کند، شمار 604 SVG و 604 JSON را اعتبارسنجی می‌کند و سرور محلی را اجرا می‌کند. حالت پیش‌فرض `auto` وجود فایل‌های local را تشخیص می‌دهد؛ بنابراین پس از extraction، برنامه SVGها و JSONها را فقط از همان سرور/کامپیوتر خودت می‌خواند.

برای production نیز نیازی به تغییر دستی config نداری؛ `build-static.sh` و Docker به‌صورت قطعی حالت `local` را در خروجی deploy فعال می‌کنند.

## چرا mapping لازم است؟

خود SVG برای هر کلمه موارد زیر را ارائه می‌دهد:

```xml
<g id="md-word-003"
   data-surah="024"
   data-aya="011"
   data-line-number="01"
   data-hafs="جَآءُو"
   data-imlaey="جاؤوا"
   data-word-index-in-ayah="3">
```

پس انتخاب و هایلایت یک کلمه مستقیماً روی SVG انجام می‌شود. QCF4 هم برای هر کلمه `verse_key` و `position` دارد.

با این حال، نگاشت این دو منبع در چند مورد باید با دقت انجام شود:

- بعضی علائم وقف در SVG یک گروه گرافیکی مستقل هستند؛
- بعضی «وَ»های عطف در SVG جدا از کلمهٔ بعدی رسم شده‌اند؛
- در QCF4 این موارد ممکن است بخشی از یک کلمهٔ منطقی باشند.

`app.js` این موارد را با نرمال‌سازی متن، کنار گذاشتن علامت‌های صرفاً گرافیکی و ادغام `data-waw-alatf` مدیریت می‌کند. برای قابلیت صوت در سطح کلمه در نسخهٔ تولیدی، خروجی mapping هر ۶۰۴ صفحه را یک‌بار تولید، بازبینی و به‌صورت JSON ثابت ذخیره کنید.

## گام‌های بعدی پیشنهادی

1. ایجاد فایل `word-map.json` تأییدشده برای تمام صفحات.
2. افزودن ترجمه و تفسیر با کلید `surah:ayah`.
3. افزودن صوت و هایلایت زمان‌دار با mapping تأییدشدهٔ کلمات.
4. ذخیرهٔ بوکمارک، آخرین صفحه و نشان‌گذاری حفظ در IndexedDB.
5. دانلود آفلاین SVGها با Service Worker.
6. جایگزین‌کردن قاب CSS نمونه با asset گرافیکی نهاییِ مورد تأیید.

## حقوق استفاده

لایسنس مخزن SVG اجازهٔ استفاده، تغییر و ساخت آثار مشتق را با شرط حفظ یکپارچگی متن قرآن اعلام می‌کند. برای فونت‌ها و داده‌های QCF4 نیز شرایط صاحب اصلی آثار، مجتمع ملک فهد، را رعایت کنید.
